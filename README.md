

# Assignments for EAPS 507 – Fall 2026

This repository contains my Python assignments for EAPS 507 during the Fall 2026 semester at Purdue University. Throughout the course, we have been learning different Python programming techniques and using libraries to organize, manipulate, and analyze data. Each assignment is saved as a Jupyter notebook (.ipynb) to document the code and work completed.

## Assignments

### 1. Python Fundamentals Through Examples

`01_Python_Fundamentals_Madhava_Pi.ipynb`

Practiced Python fundamentals by using the Madhava series to approximate pi and examining how the accuracy changes with additional calculations.

### 2. In-Class Review of Past Lectures

`02_In_Class_Review_Past_Lectures.ipynb`

Reviewed previously covered Python concepts and practiced applying them through coding exercises.

### 3. Xarray Assignment

`03_Xarray_Assignment.ipynb`

Completed an introductory Xarray tutorial to learn how to work with multidimensional datasets using labeled dimensions and coordinates.

### 4. Data Manipulation – Pandas

`04_Data_Manipulation_Pandas.ipynb`

Practiced using Pandas to load, organize, filter, and analyze data.

## Repository Organization

The assignments are organized using numbered, descriptive filenames so that each notebook can be easily identified. All four notebooks are stored in the main repository folder along with this README file.

## Purpose

The purpose of this repository is to keep my Python assignments organized throughout the semester while practicing version control using Git and GitHub. Having a record of changes also makes it easier to revisit earlier versions of my code, identify mistakes, and document my progress as I learn.
